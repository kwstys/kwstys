# kwstys

信息安全专业在读，会尝试开发一些安全工具，也会打 CTF 竞赛。

## 在做的事

**[PhishScope](https://github.com/kwstys/phishing-analyzer)** —— 离线优先的钓鱼邮件分析器

给它一封可疑邮件，输出带风险评分、判断依据和 IOC 清单的报告。全程本地运行，不联网、不上传邮件内容。

重点做中文场景：中文诱导话术、国内品牌仿冒、国内免费邮箱。这块现有开源工具基本没覆盖。

> 还在开发中，欢迎来仓库提建议。

## 关注的方向

- 邮件安全：MIME 解析、SPF / DKIM / DMARC、钓鱼特征检测
- 二进制漏洞利用（pwn）/ Web安全
- 网络协议

## 技术栈
